# План разработки: одностраничный лендинг Discord-сообщества с подпиской на рассылку

## 1. Цель проекта

Одностраничный сайт (landing page), который:
1. Презентует Discord-сообщество (что это, для кого, чем полезно).
2. Собирает e-mail адреса в рассылку (форма подписки).
3. Ведёт пользователя в Discord по invite-ссылке (главный CTA).

Ключевые метрики успеха: конверсия в клик по кнопке «Вступить в Discord» и конверсия в подписку на рассылку.

---

## 2. Технологический стек

| Слой | Выбор | Обоснование |
|---|---|---|
| Разметка/стили | HTML5 + CSS3 (без фреймворка) или Tailwind CSS | Одна страница — тяжёлый фреймворк не нужен |
| Логика | Vanilla JavaScript (ES6+) | Форма, анимации, счётчики — этого достаточно |
| Сборка | Vite (опционально) | Быстрый dev-сервер, минификация на билде |
| Приём e-mail | Сторонний сервис: Formspree / Mailchimp embedded form / Buttondown, ЛИБО свой endpoint (serverless-функция) | Без собственного бэкенда проект остаётся статическим |
| Статистика Discord | Discord Widget API: `https://discord.com/api/guilds/{GUILD_ID}/widget.json` | Живое число участников онлайн без бэкенда |
| Хостинг | GitHub Pages / Netlify / Vercel | Бесплатно, деплой из репозитория |

Минимальный вариант: **3 файла — `index.html`, `css/style.css`, `js/main.js`** — и никакой сборки. Ниже план написан под этот вариант; переход на Vite не меняет структуру блоков.

## 4. Дизайн-система (задать в `:root` в CSS)

- **Палитра**: тёмная тема в духе Discord.
  - Фон: `#1e1f22` (основной), `#2b2d31` (карточки).
  - Акцент: Discord blurple `#5865F2`, hover `#4752C4`.
  - Текст: `#ffffff` (заголовки), `#b5bac1` (обычный).
  - Успех/ошибка формы: `#23a559` / `#f23f43`.
- **Шрифт**: `Inter` или системный стек (`-apple-system, Segoe UI, Roboto, sans-serif`). Подключать через `<link>` c `display=swap` или использовать системный.
- **Радиусы**: кнопки и карточки `8px`, поля ввода `8px`.
- **Отступы**: секции `padding: 96px 0` (desktop), `64px 0` (mobile). Контейнер `max-width: 1120px; margin: 0 auto; padding: 0 24px`.
- **Breakpoints**: `768px` (планшет), `480px` (мобильный).

## 5. Блоки страницы (сверху вниз)

Каждый блок — отдельная `<section>` с `id` для якорной навигации.

### Блок 0. `<head>` и SEO
- `<title>`, `<meta name="description">`.
- Open Graph теги: `og:title`, `og:description`, `og:image` (файл `assets/og-image.png`), `og:url`.
- Favicon, `<meta name="viewport">`.
- `lang="ru"` на `<html>`.

### Блок 1. Шапка (`<header>`, sticky)
- Слева: логотип + название сообщества.
- Справа: якорные ссылки — «О нас» (`#about`), «Что внутри» (`#features`), «Отзывы» (`#reviews`), «FAQ» (`#faq`).
- Кнопка-CTA «Вступить в Discord» (акцентный цвет) — внешняя ссылка на invite.
- На мобильном: ссылки скрываются, остаётся логотип + кнопка CTA (бургер-меню опционально, для одной страницы можно без него).
- Поведение: `position: sticky; top: 0`, фон с лёгкой прозрачностью + `backdrop-filter: blur(8px)`.

### Блок 2. Hero (`#hero`) — первый экран
- H1: короткое ценностное предложение (1 строка, до 60 символов). Пример: «Комьюнити разработчиков, где отвечают быстрее Stack Overflow».
- Подзаголовок: 1–2 предложения о том, что получит участник.
- Два CTA рядом:
  1. Основной — «Вступить в Discord» (ссылка на invite, `target="_blank" rel="noopener"`).
  2. Вторичный — «Подписаться на рассылку» (плавный скролл к `#subscribe`).
- Живая статистика (строка под кнопками): «🟢 N онлайн · M участников» — подтягивается JS-ом из Discord Widget API (см. блок 10). Пока данные не загрузились — показывать статичный фолбэк («2 000+ участников»).
- Справа/фоном: мокап интерфейса Discord или иллюстрация.

### Блок 3. О сообществе (`#about`)
- 2–3 абзаца: кто мы, для кого сервер, какая атмосфера.
- Ряд из 3–4 цифр-фактов (участники, сообщений в день, год основания, число каналов) — карточки со счётчиком-анимацией при попадании в viewport (см. блок 10).

### Блок 4. Что внутри / Преимущества (`#features`)
- Сетка карточек 3×2 (grid, на мобильном — 1 колонка). Каждая карточка: иконка (emoji или SVG), заголовок, 1–2 предложения.
- Примеры карточек: «Тематические каналы», «Еженедельные ивенты», «Помощь новичкам», «Голосовые встречи», «Эксклюзивные роли», «Библиотека ресурсов».

### Блок 5. Как это выглядит (опционально)
- 2–3 скриншота сервера (каналы, ивент, обсуждение) в карусели или простой сетке.
- Если скриншотов нет — блок пропустить, это не критично для MVP.

### Блок 6. Отзывы участников (`#reviews`)
- 3 карточки: аватар (можно заглушку), ник, роль на сервере, цитата 1–2 предложения.
- Верстка: grid 3 колонки → 1 колонка на мобильном.

### Блок 7. Подписка на рассылку (`#subscribe`) — ключевой блок
- Визуально выделенная секция (фон-карточка акцентного оттенка или градиент).
- Заголовок: «Не заходишь в Discord каждый день? Получай дайджест на почту».
- Текст: что в рассылке (дайджест ивентов, лучшие треды), частота («раз в неделю»), обещание «без спама, отписка в один клик».
- Форма:
  ```html
  <form id="subscribe-form" novalidate>
    <input type="email" name="email" required
           placeholder="you@example.com" autocomplete="email">
    <button type="submit">Подписаться</button>
    <p class="form-message" role="status" aria-live="polite"></p>
  </form>
  ```
- Логика отправки — см. блок 10. Обязательно: состояние загрузки на кнопке (disabled + текст «Отправляем…»), сообщение об успехе и об ошибке.
- Под формой мелким текстом: согласие с политикой конфиденциальности (ссылка).

### Блок 8. FAQ (`#faq`)
- 4–6 вопросов через нативные `<details>/<summary>` (аккордеон без JS).
- Примеры: «Это бесплатно?», «Как получить роль?», «Правила сервера?», «Как часто приходит рассылка?», «Как отписаться?».

### Блок 9. Финальный CTA + подвал (`<footer>`)
- Крупный повтор главного CTA: заголовок «Готов присоединиться?» + кнопка «Вступить в Discord».
- Подвал: логотип, © и год, ссылки на соцсети, ссылка на политику конфиденциальности, ссылка «Правила сервера».

## 6. JavaScript (`js/main.js`) — три модуля

### 10.1. Форма подписки
```
1. Повесить submit-обработчик на #subscribe-form, event.preventDefault().
2. Валидация: непустой email, проверка регуляркой /^[^\s@]+@[^\s@]+\.[^\s@]+$/.
   При ошибке — красная рамка у input + текст в .form-message.
3. Отправка: fetch POST на ENDPOINT (константа в начале файла).
   - Вариант A (рекомендуемый для старта): Formspree — POST на
     https://formspree.io/f/{FORM_ID} с заголовком Accept: application/json.
   - Вариант B: свой serverless endpoint (Netlify Function / Vercel Function),
     который кладёт email в список рассылки через API Mailchimp/Buttondown.
4. UI-состояния: idle → loading (кнопка disabled) → success («Проверь почту!»)
   или error («Что-то пошло не так, попробуй ещё раз»).
5. После успеха — очистить поле, задизейблить повторную отправку на 5 сек.
```

### 10.2. Живая статистика Discord
```
1. В настройках Discord-сервера включить Server Widget (Settings → Widget).
2. fetch('https://discord.com/api/guilds/{GUILD_ID}/widget.json')
   → поле presence_count = число онлайн.
3. Подставить в hero. При любой ошибке fetch — оставить статичный фолбэк,
   ничего не ломать (try/catch, молча).
```

### 10.3. Анимации при скролле
```
1. IntersectionObserver на секции: при появлении добавлять класс .visible
   (CSS: opacity 0→1 + translateY(16px)→0, transition 0.5s).
2. Счётчики цифр в блоке «О сообществе»: при появлении в viewport
   анимировать от 0 до значения из data-target за ~1.5 сек (requestAnimationFrame).
3. Уважать prefers-reduced-motion: если включено — отключить анимации.
```

## 7. Адаптивность — чек-лист

- [ ] 320–480px: одна колонка везде, кнопки на всю ширину, hero без иллюстрации или с ней под текстом.
- [ ] 481–768px: сетки features/reviews — 2 колонки.
- [ ] 769px+: полная раскладка.
- [ ] Форма подписки: input + кнопка в строку на desktop, столбиком на mobile.
- [ ] Тап-таргеты ≥ 44×44px.

---

## 8. Доступность (a11y)

- Семантика: `header / main / section / footer`, один `<h1>`, иерархия заголовков без пропусков.
- У всех изображений `alt`; у декоративных — `alt=""`.
- Контраст текста к фону ≥ 4.5:1 (проверить акцентные кнопки).
- Форма: `<label>` (можно визуально скрытый), `aria-live="polite"` на сообщении статуса.
- Полная навигация с клавиатуры, видимый `:focus-visible`.

## 11. Критерии приёмки (Definition of Done)

- [ ] Страница корректно выглядит на 320px, 768px, 1440px.
- [ ] Кнопка «Вступить в Discord» открывает рабочий invite в новой вкладке.
- [ ] Форма подписки: валидирует email, показывает загрузку/успех/ошибку, письмо реально попадает в список рассылки.
- [ ] Онлайн-счётчик подтягивается из Discord API; при недоступности API страница не ломается.
- [ ] Lighthouse: Performance ≥ 90, Accessibility ≥ 90, SEO ≥ 90.
- [ ] Нет ошибок в консоли браузера.
- [ ] Ссылка-превью красиво разворачивается в Telegram/Discord (OG-теги).
